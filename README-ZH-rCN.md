# MMD Play Mode Preview

[English](README.md)

## 介绍

**MMD Play Mode Preview 不再提供 VMD 求解及转换支持，仅预览已转换的 AnimationClip。** 如需求解或转换，请使用以下独立仓库：

- 转换器：[VMD Converter Window](https://github.com/Vera-Firefly/VMD-Converter-Window)
- 离线转换：[VMD Converter Core](https://github.com/Vera-Firefly/VMD-Converter-Core)

在 Unity Play Mode 中预览 VRChat 虚拟形象的动作、镜头动画和音频。当前版本：**3.0.0**。

## 依赖

- **Unity 2022.3** 和 **VRChat Avatars SDK**。
- **Gesture Manager 3.9.8**，已在包依赖中声明；预览面板会为选中的形象配置 Gesture Manager。
- 已有的动作、镜头 **AnimationClip** 及可选的 **AudioClip**。VMD 文件需先通过独立转换工具转换；本包不依赖 VMD Converter Window 或 VMD Converter Core。
- 录制和压缩使用内置 **Windows x64 FFmpeg 8.0**，包含 libx264，无需另外安装或配置 PATH。目前录制支持 **Built-in Render Pipeline**。FFmpeg 缺失或编辑器平台不支持时，仅禁用录制和压缩，其它预览功能仍可使用。
- **AudioLink 为可选依赖**。未安装时禁用“AudioLink接入”，不影响其它功能。需要在**进入 Play 前**，场景层级中存在激活且启用的 AudioLink 组件，本次会话才可接入。材质需自行启用 AudioLink 效果；lilToon 材质还需关闭 **AudioLink As Local**。
- **OBS 输出为可选功能**，已内置 Windows x64 Spout 发送端，需要 **Direct3D 11/12** 和 **Built-in Render Pipeline**。OBS 端需安装与其版本兼容的 [Spout2 插件](https://github.com/Off-World-Live/obs-spout2-plugin/releases)，Unity 与 OBS 须使用同一块显卡。原生发送插件缺失或平台不支持时，仅禁用画面输出。

## 用途及功能

- 播放、暂停、结束、重置、拖动进度及循环播放现有 AnimationClip，同步播放音频和镜头动画。
- 提供 **0.1×–3×** 倍速滑条，以及 **0.1×、0.2×、0.5×、1×、2×** 快捷按钮；音频音调随倍速变化。
- 支持镜头动画和自由视角控制，可设置视频、图片或纯色背景；视频片段与预览时间同步。
- 按当前摄像机宽高比和原生画面尺寸录制 **60 fps MP4**，最高 1080p，保留同步音轨，暂停时间不计入视频。
- 后台压缩视频并保留原文件，可从面板打开上次输出所在位置。
- 可选接入 AudioLink，驱动兼容材质的音频效果，录制时同样可用。
- 通过 **Spout2** 将纯净的预览摄像机画面直接送入 OBS，可设置输出名称和分辨率，不受编辑器窗口尺寸限制。
- 面板支持简体中文、英文和日文。

**开始使用**

1. 安装本包和必要依赖。将附带的 **MMD Play Mode Preview** 预制体放入场景，或通过 **VeraFirefly > MMD Play Mode Preview > Create MMD Play Mode Preview** 创建组件。
2. 选择场景中激活且具有 VRC Avatar Descriptor 的形象，按需设置动作、音频、镜头动画，并选择用于决定播放时长的资源；需要时配置预览背景。
3. 点击组件面板中的**进入 Play Mode 预览**。请通过此按钮启动预览会话；从其它入口进入 Play 时，该面板的预览功能会禁用。
4. 在“播放设置”调整倍速，通过“播放控制”播放、暂停、重置、拖动进度或结束。内置视频录制期间（包括暂停）锁定倍速，并禁用循环、重置和进度拖动；启用“同步 OBS 录制”时禁用循环、暂停、重置和进度拖动。

**镜头及背景**

自由视角操作：按住鼠标右键拖动旋转，**W/A/S/D** 移动，**Q/E** 向下／向上，滚轮调整移速；按住中键旋转，滚轮调整距离。使用镜头动画时，可勾选**自由视角控制**切换为手动控制。

视频背景：将视频导入 Unity，启用**预览背景**并指定 **VideoClip**。设置**预览中开始时间**和**视频片段起点／终点**（秒，终点为 0 表示视频结尾）。例如，预览开始时间 5、片段起点 10、终点 20，会在预览的第 5–15 秒显示视频的第 10–20 秒；其余时间显示图片或纯色背景。指定背景后只定位当前画面，点击**播放**才开始播放视频；暂停和结束时保持对应时间的画面。播放前准备或跳转超时时会保留背景配置，点击**播放**后自动重试加载视频。视频随拖动进度、循环及倍速同步，内置录制时等待对应视频帧。视频原声静音，配乐请放入 MMD 音频栏；内置录制期间背景设置锁定。请使用 Unity 所在平台支持的视频格式，例如 H.264 MP4。

**内置视频录制及压缩**

录制视频前，先结束播放，再勾选**视频录制**，通过文件夹图标选择输出位置。点击**播放**开始录制，**暂停**暂存进度，再次**播放**继续同一个文件；点击**结束**或播放完成后保存 MP4。可提前勾选**录制后压缩**，也可录制后点击**压缩上次输出 (FFmpeg)**。**上次输出**为只读输入框，右侧文件夹图标可打开所在位置。

录制采用逐帧方式，复杂场景可能慢于实时。录制期间试听静音，成片保留同步的音频片段。AudioClip 的 Load Type 须设为 **Decompress On Load** 并完成加载；音轨不包含麦克风、其它场景音源或 AudioMixer 效果。压缩会另存文件，已高度压缩的视频可能没有明显体积收益。

录制期间，场景时间及虚拟形象的 Animator／FX 控制器按录制倍速逐帧推进；等待背景视频解码及暂停录制时冻结，结束后恢复时间与 Animator 更新设置。自行使用不受场景时间控制的脚本、着色器或动画系统不保证同步。

**AudioLink 接入**

接入 AudioLink 时，在进入 Play 前放置并激活 AudioLink 组件，进入后在“播放设置”勾选 **AudioLink接入**。该开关默认关闭：关闭时停用检测到的 AudioLink 对象，勾选后激活并接入预览音源；退出预览后恢复原激活状态和音源设置。进入 Play 后才新建或激活的 AudioLink 需等下次会话才能接入。建议场景只保留一个激活的 AudioLink 分析器；存在多个时使用检测到的第一个。

**OBS 画面输出**

1. 在 [OBS Spout2 插件发布页](https://github.com/Off-World-Live/obs-spout2-plugin/releases)选择与本机 OBS 版本兼容的安装包，关闭 OBS 后安装，再启动 OBS。Unity 发送端已随本包提供，无需另装 KlakSpout。
2. 通过面板进入 Play Mode 预览，在 **OBS 画面输出**中设置唯一的 ASCII **输出名称**和**输出尺寸**（默认 1920×1080，宽高各为 16–4096），然后勾选 **Spout2 输出**。修改名称或尺寸前先关闭输出。
3. 在 OBS 的“来源”中点击 **+ → Spout2 Capture**，选择 Unity 面板“当前输出”显示的名称；重名时该名称会自动附加编号。将来源适配到 OBS 画布，并按需调整 OBS 的画布和输出分辨率。
4. 配乐需要单独接入：在 OBS 添加**应用程序音频采集**并选择 Unity，点击预览面板的**播放**，确认 OBS 音频电平表有响应。避免同时从桌面音频重复采集同一声音。
5. 在 OBS 开始录制或推流。输出仅包含预览摄像机画面及其背景。暂停时保持预览姿态；结束播放会重置进度，发送端仍保持可用。OBS 获得焦点后 Unity 仍在后台运行；请保持 Unity Game 视图打开，使摄像机持续渲染。
6. 完成后取消 **Spout2 输出**，或退出预览。发送端会释放，摄像机输出目标及宽高比恢复。

Spout 只传输画面。实时输出与内置逐帧录制互斥，启用输出后请通过 OBS 录制或推流；此时沿用正常实时播放，不依赖 FFmpeg。没有 **Spout2 Capture** 来源时，检查插件安装及 OBS 版本兼容性；能选择来源但黑屏时，在 Windows 图形设置中将 Unity 与 OBS 指定到同一块显卡，确认 Unity 使用 Direct3D 11/12，并保持 Game 视图打开。音频缺失时检查 Unity 预览是否正在播放，以及 OBS 应用程序音频采集是否选中了正确的 Unity 窗口。

**同步 OBS 录制**

1. 在 OBS 的**工具 → WebSocket 服务器设置**启用服务器。使用 OBS WebSocket **5.x** 协议；OBS 28 起内置服务器。查看其端口和密码。
2. 在 MMDPMP 启用 **Spout2 输出**和**同步 OBS 录制**，输入 WebSocket 地址（本机默认 `ws://127.0.0.1:4455`）及密码，点击**连接 OBS**。地址保存在本机编辑器设置，密码仅保存在内存中，脚本重载或退出预览后需重新填写并连接。
3. **播放**会启动 OBS 录制，并在 OBS 确认后播放动作和音频；**结束**或播放完成后停止并保存。联动时强制关闭**循环播放**，并禁用**暂停、重置和进度拖动**，仅允许播放和结束。关闭组件、退出预览或断开连接也会尝试结束本次录制。此开关仅控制录制，不控制直播推流。
4. OBS 已有独立录制时不会接管，请先停止原录制。Spout 画面可用不代表 WebSocket 服务器已启用；若提示拒绝连接，先在 OBS 启用 WebSocket 服务器，再核对地址和端口。录制启动失败时检查 OBS 的录制路径、编码器及日志。

WebSocket 控制存在通信及编码器启动延迟，不保证逐帧精确同步。断线时 Unity 面板会显示错误，请在 OBS 确认录制状态，重新连接后再操作；取消联动开关可继续正常预览。输出文件位置、编码和质量均由 OBS 的录制设置决定。
